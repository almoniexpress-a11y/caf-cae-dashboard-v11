# CAF CAE Pro v38 — Core Platform

V38 keeps the working v37 base and turns the navigation into a cleaner operating platform.

## Included
- Cleaner role-based navigation (fewer sidebar items)
- One practice work queue with New / Waiting / In Work / Completed filters
- Global/table search
- Permanent practice visibility through backend watchers
- Team Bangla/Italy direct transfer to Italy or Commercialista
- Standard 14-stage practice status flow
- Cleaner owner/progress presentation
- Refresh-safe session: a temporary API/network validation failure no longer throws the operator back to login
- Existing v37 backend, Supabase, documents, membership, agent credit, tickets and role permissions preserved

## Deploy
Replace the current project with this package, then commit/push to the existing GitHub/Vercel project. Backend changes are not required for this V38 UI/core release.
