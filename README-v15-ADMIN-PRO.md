# CAF CAE Dashboard v15 — Admin Portal Pro

This version upgrades the Admin portal while keeping the v12 secure auth system and v14 role base.

## Included

- Admin Portal Pro with CGN blue header style.
- User/employee creation with role, salary, credit, active/block status.
- Agent control: block/unblock, credit adjustment, service permission keys.
- Admin can create practices and assign to Team Bangla, Team Italy, Commercialista, or Agent source.
- Daily/monthly/yearly sales dashboard from practices, commercialista invoices/sales, and manual admin sales.
- Team daily work report view for Bangla and Italy.
- Commercialista overview for companies, invoices, F24 and closures.
- Product price and agent commission management from Admin.
- Promotion/ads slide and popup management for agent/team/commercialista dashboards.
- Complaint/problem registry for order issues.
- Portal settings panel for later structure/design changes.

## Push

Copy this folder into the live repo root, then:

```powershell
git add -A
git commit -m "Upgrade v15 admin portal pro"
git push
```

No old v11 SQL is needed. Keep existing v12 secure users/passwords.
